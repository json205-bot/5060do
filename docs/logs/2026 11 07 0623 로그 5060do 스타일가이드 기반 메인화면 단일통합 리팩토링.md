  `--color-ink: #16232e` 유지.

  - Tailwind 간격 토큰은 루트 18px에 비례해 커지므로(`h-16`=72px), 52/56/64/72px는
    `min-h-[56px]`·`h-[64px]`처럼 px 임의값으로 고정했다.
- `scripts/verify-style-guide.mjs`: 390·412·768·820·1280px에서 3대 원칙과 폼 규격을
  CDP로 측정하고 스크린샷을 남기는 신규 검증 스크립트.
- 배포: `npm run build` 후 `deploy_www.sh /volume1/workspace/dev/5060do/out 5060do`.
