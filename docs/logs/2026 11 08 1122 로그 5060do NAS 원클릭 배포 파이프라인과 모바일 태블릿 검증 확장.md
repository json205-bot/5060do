- 수동 3단계(`npm run build` → `deploy_www.sh` → `www_index.sh`)를 `npm run deploy:nas` 한 명령으로 묶는다.

## 4. 남은 위험

- Vercel Production 실도메인은 여전히 발급되지 않았다. URL이 생기면 `npm run verify:vercel:live -- --url <URL>`(21항목)을 실행할 준비만 되어 있다.
- `deploy:nas`는 NAS 공유 경로가 `Z:`로 마운트되어 있고 SSH 키·NAS 접근이 가능한 PC를 전제로 한다. 마운트가 끊기면 빌드는 되지만 NAS 동기화 단계에서 실패한다.
- 모바일 검사는 헤드리스 Chrome 에뮬레이션(390×844, 터치 활성)이다. 실기기 사파리·삼성 인터넷의 동작 차이는 포함하지 않는다.
- Vercel 루트 빌드는 `out/`을 덮어쓴다. 작업 순서상 반드시 `npm run deploy:nas`를 마지막에 실행해야 한다.
