# 5060do 반응형 웹 프로토타입 구축

## 결론

Next.js 16.4.5(App Router) + TypeScript + Tailwind CSS v4로 신중년 맞춤 반응형
수강신청 프로토타입을 구축하고, 타입체크·빌드·3개 뷰포트·신청 흐름을 실제
헤드리스 Chrome으로 검증했다. 전 항목 PASS.

## 실행

1. `npx create-next-app` 템플릿을 로컬 임시 폴더에서 생성 후 `Z:\dev\5060do`로 복사.
   - npm이 UNC 경로에서 동작하지 않아 로컬 디스크에서 스캐폴딩했다.
2. 템플릿의 Google Fonts·Turbopack CSS 로더를 제거하고 `@tailwindcss/postcss` 표준 구성으로 교체.
3. `src/data/programs.json`에 아카이브(2026-11-04 수집분)의 실제 강좌 3건과 마감 1건을 적재.
4. `src/app/page.tsx`에 헤더·히어로·카드 그리드·상세 모달·신청 폼·완료 화면을 구현.
5. `scripts/verify-viewports.mjs`로 Chrome CDP 기반 뷰포트·흐름 검증.

- 프로토타입이므로 실제 인증·결제·DB는 없다. 얼럿 문구가 실제 승인처럼 보이지 않도록 화면에 안내 문구를 넣었다.
- 상담전화·위치는 예시 값이며, 실제 값은 센터 확인이 필요하다.
- 크롤링 아카이브(`assets/`, 6.3GB)는 `.gitignore`로 저장소에서 제외했다.
