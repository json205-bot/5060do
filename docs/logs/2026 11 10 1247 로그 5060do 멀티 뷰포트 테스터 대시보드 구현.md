# 5060do 멀티 뷰포트 테스터 대시보드 구현

## 1. 목표

- 데스크탑에서 스마트폰·태블릿·갤럭시 폴드 반응형 화면을 한 화면에서 동시에 검증하는 개발용 대시보드를 만든다.
- 스마트폰 2종, 태블릿 2종, 갤럭시 폴드 4종 = 총 8개 뷰포트를 세로 스크롤 섹션으로 제공한다.
- 상단 고정 컨트롤 바에서 URL 적용·전체 새로고침·40~100% 배율 조절·섹션 앵커 점프를 지원한다.
- 기존 프로젝트 구조(`app/tools/...`)에 통합하고 정적 export 빌드·NAS basePath와 호환되게 한다.

## 2. 구현

- `src/app/tools/viewport-tester/page.tsx` 신규 (클라이언트 컴포넌트)
  - 상단 sticky 헤더: 대상 URL 입력/적용, 전체 새로고침, 40~100% 배율 슬라이더(기본 60%), 스마트폰·태블릿·갤럭시 폴드 앵커 버튼.
  - URL 정규화: 상대 경로 유지, `localhost`는 `http://`, 도메인만 입력하면 `https://` 자동 보정. 교차 출처일 때 X-Frame-Options·CSP `frame-ancestors` 안내 표시.
  - 디바이스 프레임: 기기별 베젤·화면 모서리, 폰 노치·홈 인디케이터, 해상도 뱃지, 개별 회전 토글, 새 창 열기.
  - iframe은 실제 CSS 뷰포트 크기(390×844 등)를 유지하고 프레임 전체에 `transform: scale()`만 적용해 배율을 바꾼다.
  - 하단에 iframe 제약·상대 경로·외부 출처 주의사항 패널.
- `scripts/verify-viewport-tester.mjs` 신규
  - `out/`을 `/5060do` 접두사로 서빙하는 정적 서버와 헤드리스 Chrome CDP를 사용.
  - 8개 프레임 사양·iframe 동일 출처 로드·배율 40/100%·URL 적용·전체 새로고침·개별 회전·앵커 점프·교차 출처 안내를 자동 검증하고 스크린샷·JSON 증거를 남긴다.
