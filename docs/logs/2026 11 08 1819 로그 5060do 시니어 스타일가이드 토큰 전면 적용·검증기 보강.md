- `docs/STYLE_GUIDE.md`의 시니어 3대 원칙(고대비·큰 글자·큰 터치)을 Tailwind v4 `@theme` 토큰으로 전 페이지에 일괄 적용한다.

- `src/app/globals.css`

  - `body`에 `font-size: 1rem`, `line-height: 1.6` 명시.

  - `text-[13px]`~`text-[18px]`를 `text-xs/sm/base` 토큰으로 교체.
  - 클래식 화면 하드코딩 HEX를 `classic-*`·`accent-*` 토큰으로 교체.
  - 48px 미만 터치 타깃(검색 버튼, 페이지 인디케이터, 텍스트 링크, 전화 링크 등)을 48x48px 이상으로 확장.
  - 상태 배지를 `status-*-soft` 토큰에 바인딩.
- `scripts/verify-style-guide.mjs`
  - 390/768/1280 뷰포트에서 모던·클래식 두 화면을 모두 감사.

  - 페이지 크기(30장)에 맞춰 카드 수 기대값을 47→30으로 정정.
