## 5. 남은 위험·한계

1. PC·모바일 원본 로고가 동일 파일이라 현재 두 뷰포트의 로고 모양이 같다. 원본 사이트도
   같은 이미지를 쓰므로 의도된 결과이나, 별도 모바일 전용 로고가 생기면 파일만 교체하면 된다.
2. 원본 PNG가 394x73(헤더) 기준이라 고해상도(2x) 화면에서는 표시 크기 243px 대비
   원본이 1.6배 수준이다. 확대 시 약간 흐려질 수 있으며, 2x 자산이 확보되면 교체가 좋다.
3. 로고 이미지의 여백·색은 원본 그대로라 헤더 흰 배경과 푸터 어두운 배경에 맞춰
   각각 다른 파일을 쓴다. 배경색을 바꾸면 대비를 다시 확인해야 한다.
4. `verify-logos.mjs`는 헤더/푸터 로고만 판정한다. 페이지 전체 이미지 회귀는 기존
   `verify-viewports.mjs`가 담당한다.
