# 5060do Vercel 루트 E2E·접수중 전역 임박순·챗봇 실시간 데이터 연동

## 1. 목표

- E2E 스크립트 하나로 NAS 서브패스(`/5060do`)와 Vercel 루트(`""`)를 모두 기계 검증.
- [더보기]로 다음 페이지가 붙어도 접수중 그룹 전체가 잔여석 임박순을 유지.

## 4. 한계·위험

- 실제 Vercel 클라우드 배포는 수행하지 않았다. 로컬 루트 빌드·정적 서빙·E2E로만 재현했다.
- 접수중 7건이 모두 첫 페이지에 있어, 페이지 경계를 넘는 접수중 재정렬은 현재 데이터로 직접 발생하지 않는다. 코드 경로는 `mergeProgramPage()`로 처리한다.
- 챗봇 무료 강좌 목록은 전체 첫 30건(`overview`) 기준이다. 활성 강좌가 30건을 넘으면 일부가 안내에서 빠질 수 있다.
- UNC(`\\x4\workspace\...`) 작업 디렉터리에서는 `npm run`이 cmd.exe 제약으로 실패하므로 Node 실행 파일을 직접 호출했다.
