## 5. 남은 위험

1. Vercel 원격 도메인 실배포는 아직 없다. Import 후 `node scripts/verify-vercel-live.mjs <URL>`로 같은 21항목을 재검해야 한다.
2. `match_documents()` RPC는 여전히 SQL 파일로만 제공되며, 클라이언트는 번들 벡터로 검색한다(설계상 자립).
3. 부산/기타 지역 판정은 제목·본문 키워드 기반 규칙이다. 오분류가 보이면 `src/lib/jobs.ts` `deriveJobRegion()`의 지역 목록을 보강해야 한다.
4. 로컬 폴백 데이터는 1.7MB 지연 청크다. 최초 폴백 시 내려받는 양이 크므로, 오프라인 사용이 잦아지면 폴백용 축약본 분리를 검토한다.
5. `verify-vercel-live.mjs --no-build`는 반드시 Vercel 루트 빌드(`out`)에만 쓴다. NAS basePath 빌드에 돌리면 `/5060do` 누출 검사가 실패한다(2026-11-08 실제 오진 1회).
