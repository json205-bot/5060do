# 5060do 원본 반응형(Classic)·축소 모던(Modern) 듀얼 버전 구축

## 1. 작업 내용

- `/5060do/` 기존 축소 모던형 유지, `/5060do/classic/` 원본 메뉴 반응형 버전 신설
- 두 화면 최상단에 상호 전환 배너(`VersionSwitcher`) 배치
- Classic: 로고·로그인/회원가입·브로슈어·통합검색 유틸리티, 8대 GNB 메가드롭다운, 모바일 슬라이드 드로어 + 8대 아코디언
- Classic 본문: 비주얼 롤링 3종, 사업안내·교육신청·일자리정보 탭 카드, 새 소식·일자리 그리드, 바로가기, 층별 시설·상담 안내
- 정적 export 중첩 라우트 RSC 페이로드 404 보정 스크립트 추가
