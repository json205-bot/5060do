# 5060do RAG RPC 안전 폴백·채용정보 일별 증분 크롤러·NAS 재배포

## 1. 목표

- REST API로는 DDL을 실행할 수 없으므로, `public.match_documents` RPC가 존재할 때만 선택 호출하고 실패하면 클라이언트 번들 벡터 검색으로 즉시 폴백하는 안전 가드를 만든다.
- 기존 채용공고 2,034건 외 신규 공고만 수집해 Supabase `public.jobs`에 Upsert하는 일별 증분 크롤러를 추가한다.
- 전체 회귀(E2E 80/80)와 NAS 운영 배포(25/25)를 다시 통과시킨다.

## 4. 남은 위험

- `match_documents` RPC는 현재 실제로 존재하며 anon 키로 호출된다. 이후 삭제되어도 챗봇은 번들 검색으로 계속 동작한다.
- 크롤러는 첫 페이지가 모두 기존 id면 그 테마 스캔을 멈춘다. 사이트가 최신순 정렬을 바꾸면 `JOBS_CRAWL_MAX_PAGES`를 늘려야 한다.
- 기본 실행은 Supabase에만 Upsert하고 로컬 `jobs_all.json`은 바꾸지 않는다. 번들 폴백까지 갱신하려면 `--update-local`을 함께 실행한다.
- Vercel Production 실도메인은 여전히 발급되지 않아 실도메인 21항목 검증은 대기 상태다.
