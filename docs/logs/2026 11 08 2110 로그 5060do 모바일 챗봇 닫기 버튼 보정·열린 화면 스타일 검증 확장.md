# 5060do 모바일 챗봇 닫기 버튼 보정·열린 화면 스타일 검증 확장

## 1. 목표

- 모바일(390px) 챗봇 패널 열림 시 닫기 버튼이 화면 밖으로 밀리지 않게 헤더를 고정하고 높이를 보정한다.
- 챗봇·전체 메뉴 드로어·상세 모달이 열린 상태에서도 시니어 스타일가이드(14px 폰트 하한, 48px 터치, 4.5:1 대비, 가로 스크롤 0px)를 기계 검증한다.
- NAS 실배포와 원격 미러(Gitea·GitHub) 동기화까지 완결한다.

## 2. 구현

- `src/components/ChatbotWidget.tsx`
  - 모바일 패널 높이를 `h-[85vh]` → `h-[88dvh]`로 교체하고 데스크톱 `md:h-[580px]`는 유지.
  - 헤더를 `sticky top-0 z-10 shrink-0`로 고정, 하단 경계선 추가.
  - 닫기 버튼을 `bg-white text-brand-800` 고대비로 바꾸고 `touch-target` + `size-12`(48px) 유지.
  - 오버레이 클릭·Esc 닫기, safe-area 입력창 패딩은 그대로 보존.
- `src/app/page.tsx`
  - 상세 모달 닫기 버튼에 `data-testid="detail-modal-close"`, 신청 CTA에 `data-testid="detail-modal-apply"` 추가(검증기 선택자 고정).
- `scripts/verify-style-guide.mjs`
  - 감사 함수를 `auditExpression(scope)`로 일반화해 페이지 전체와 열린 레이어 내부를 같은 규칙으로 검사.
  - 챗봇 패널 측정기(`CHATBOT_MEASURE`): 패널/닫기 버튼 뷰포트 포함, 헤더 `position: sticky`, 닫기·퀵 칩·보내기 48×48px, 입력창 52px·14px 하한, 메시지 14px 하한, 가로 스크롤 0px.
  - 드로어 측정기(`DRAWER_MEASURE`): 닫기 48px 이상, 바로가기 3개, 링크 48×48px, 뷰포트 포함.
  - 모달 측정기 확장: 닫기 48px 이상·뷰포트 포함, 신청 CTA 56px.
  - 챗봇 Esc 닫기·오버레이 클릭 닫기 인터랙션 검증 추가.
  - 열린 화면 스크린샷과 `verification.json`을 `docs/evidence/`에 저장.

## 4. 남은 위험

- `h-[88dvh]`는 동적 뷰포트 단위라 구형 브라우저(Chrome 108 미만 등)에서는 높이 계산이 어긋날 수 있다. 대상 사용자는 최신 모바일 브라우저 기준으로 확인했다.
- 가상 키보드가 올라온 상태의 실제 기기 동작은 헤드리스 검증 범위 밖이다. safe-area 하단 패딩과 88dvh 조합으로 완화했을 뿐, 실기기 QA는 별도다.
- 열린 레이어 감사는 페이지 뒤 배경 요소도 함께 훑는다. 현재는 모두 통과하지만, 배경에 48px 미만 요소가 새로 생기면 레이어 검증도 같이 실패한다.
