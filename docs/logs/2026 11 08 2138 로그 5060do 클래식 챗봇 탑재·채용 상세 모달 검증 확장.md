# 5060do 클래식 챗봇 탑재·채용 상세 모달 검증 확장

## 1. 목표

- 원본 메뉴형 화면(`/classic/`)에도 모던 화면과 같은 시니어 RAG 챗봇 위젯을 탑재한다.
- 채용정보 상세 모달이 열린 상태를 스타일가이드 검증기(`scripts/verify-style-guide.mjs`)에 추가한다.
- 품질 검사·E2E·NAS 실배포·원격 미러(Gitea·GitHub) 동기화까지 완결한다.

## 2. 구현

- `src/app/classic/page.tsx`
  - `ChatbotWidget`과 `usePrograms("전체")`를 도입하고 `overview`, `activePrograms`, `counts`, `onOpen`을 모던 화면과 동일하게 연결.
  - 위젯을 푸터 아래, 모바일 드로어(`z-50`) 앞에 배치해 드로어가 위젯 트리거(`z-40`)를 덮도록 레이어 순서 정리.
  - 챗봇 열림 시 클래식 모바일 드로어를 함께 닫도록 `onOpen` 콜백에서 `setMobileOpen(false)` 호출.
- `scripts/verify-style-guide.mjs`
  - `JOB_MODAL_MEASURE` 추가: `job-detail-modal` 열림 시 닫기 버튼 48×48px·뷰포트 포함, 원문 링크 56px CTA, 가로 스크롤 0px.
  - 채용 상세 모달 내부 전체 글자 14px 하한·터치 타깃 48×48px·대비 4.5:1 감사(`layerAudit`) 연결.
  - 채용 상세 Esc 닫기·오버레이 클릭 닫기·닫기 버튼 클릭 인터랙션 검증 추가.
  - 클래식 화면 390/768/1280에서 챗봇 트리거 표시·48×48px를 확인하고, 390에서 패널 열림·닫기 48px·글자/터치/가로 스크롤·Esc 닫기까지 검증.
