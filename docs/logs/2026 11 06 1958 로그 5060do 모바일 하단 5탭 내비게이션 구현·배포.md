# 5060do 모바일 하단 5탭 내비게이션 구현·배포

## 1. 작업 범위

- 모바일 전용 하단 고정 내비게이션 5탭(홈·교육신청·채용정보·공지사항·전체) 추가
- '전체' 탭 → 전체 메뉴 드로어(바로가기·센터 안내·상담/오시는 길)
- 50~60대 기준 터치 타깃·라벨 크기·활성 상태 시각 구분
- 나스 www 재배포 및 실서버 E2E

## 2. 변경 파일

| 파일 | 변경 |
|---|---|
| `src/app/page.tsx` | 하단 내비게이션, 전체 메뉴 드로어, 스크롤 스파이, 헤더 메뉴 모바일 숨김, 래퍼 `pb-20 md:pb-0` |

| `docs/PLAN.md` | 7장 추가 |
| `docs/evidence/*` | 빌드·배포·HTTP·E2E 로그, 스크린샷, `verification.json` |

## 3. 구현 상세

- 탭: `fixed bottom-0 left-0 right-0 z-40 ... md:hidden`, 높이 `h-16`(18px 루트 기준 실측 72px), `pb-[env(safe-area-inset-bottom)]`.
- 홈 탭: `window.scrollTo({ top: 0, behavior: "smooth" })`.
- 교육신청·채용정보·공지사항: `scrollIntoView` + `scroll-padding-top: 7rem` 오프셋.
- 활성 판정: 스크롤 시 각 섹션 상단 - 140px ≤ 0 인 마지막 섹션, 상단이면 홈.
- '전체' 탭: `role="dialog" aria-modal` 드로어, Escape·배경 클릭·닫기 버튼, body 스크롤 잠금, 포커스 복귀.
- 드로어 바로가기: 닫힘 전환 후 `requestAnimationFrame`으로 스크롤(스크롤 잠금 해제 후 실행).

## 5. 남은 위험

- 실기기(iOS/Android) safe-area는 헤드리스 Chrome으로 확인하지 못했다.
- 드로어는 콘텐츠가 길면 스크롤이 필요하다(최대 88vh).
- 배포는 수동(`build` → `deploy_www.sh` → `www_index.sh`)이며 자동화되어 있지 않다.
